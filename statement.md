# Project Statement

## Title
Smart Library Management System

## Problem Statement
Traditional library systems often depend on manual registers or basic software that only records books and transactions. Such systems can make searching, tracking overdue books, monitoring inventory and discovering relevant books inconvenient. The proposed Smart Library Management System provides a centralized Java application for managing books and members, issuing and returning books, calculating fines, generating reports and suggesting books using borrowing history.

## Scope
The system covers book catalog management, member registration, issue/return transactions, search, fine calculation, basic analytics and rule-based recommendations. It is intended for a college or institutional library.

## Target Users
- Librarians
- Library administrators
- Students/members

## High-Level Features
- Book CRUD
- Member CRUD
- Book search
- Issue and return
- Automatic fine calculation
- Recommendation engine
- Reports/dashboard
- Validation and error handling

## Limitations
This academic version is a desktop application. It does not include cloud deployment, RFID hardware or production-grade authentication.
